# iOS App Build Guide

The app is a mobile-first Next.js PWA that can be installed on iOS two ways.
All source changes work for both paths — there is one codebase.

## Option A — Install as a PWA (no App Store, fastest)

1. Deploy the app (e.g. `npm run build` then host `out/` on Vercel, or `npm run dev` on your network).
2. Open the URL in Safari on the iPhone.
3. Share → **Add to Home Screen**.
4. The app launches full-screen, standalone, with its own icon — like a native app. It also works offline via the service worker.

## Option B — Native iOS app via Capacitor (App Store)

Run these steps on a Mac with Xcode installed.

```bash
npm install
npm run build                       # static export into out/

npm install @capacitor/core @capacitor/cli @capacitor/ios
npx cap add ios                     # creates the ios/ Xcode project
npx cap sync ios                    # copies out/ into the native shell
npx cap open ios                    # opens Xcode
```

In Xcode: select a signing team, set the display name/version as desired,
then **Product ▸ Run** for the simulator or **Product ▸ Archive** to build for
TestFlight / the App Store.

The Capacitor config is already committed (`capacitor.config.json`):

- App ID: `com.imranarefin.businessos`
- Web dir: `out` (the Next.js static export)
- iOS scheme: `https`, dark background `#0b1220`

## Notes

- `next.config.ts` uses `output: "export"` so the whole app is a static bundle — ideal for Capacitor and free static hosting.
- Data currently persists on-device (localStorage). The store (`lib/store.tsx`) is isolated so a Supabase sync layer can be added without touching UI code.
- App icon is generated by `scripts/gen-icons.js` (`npm run build` does not regenerate it; run `node scripts/gen-icons.js` if you change it).
